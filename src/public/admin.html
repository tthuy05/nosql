Nhật Ký Chuyển Đổi Trạng Thái (Timeline)
    Hướng Dẫn Mở P3X Redis UI
    Trên máy tính của bạn, P3X Redis UI đang chạy dưới dạng Ứng dụng Desktop (.exe) với cửa sổ phần mềm riêng biệt (không phải máy chủ web cổng 7843).
    Cách 1: Mở ứng dụng Desktop (Khuyên dùng - Đang có sẵn)
    1. Nhìn xuống thanh Taskbar dưới đáy màn hình Windows, click vào biểu tượng P3X Redis UI.
    2. Hoặc bấm phím Windows, gõ tìm P3X-Redis-UI và mở lên.
    3. Trong P3X, bấm "Add / Settings" và điền thông số:
      • Host: 127.0.0.1
      • Port: 6379
      • Password: Để trống
    4. Bấm Test Connection -> Save & Connect để quan sát 4 hàng đợi và các khóa order:*.
    Cách 2: Nếu muốn mở trên trình duyệt (Port 7843)

    Địa chỉ http://localhost:7843 chỉ dùng khi bạn khởi chạy bằng Docker Compose (docker compose up -d).

    Mở thử http://localhost:7843 (Nếu đang bật Docker)
